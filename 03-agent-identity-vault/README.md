# Agent identity with Okta + Vault

**Status:** Not started

## Goal
Give the agent its own identity: an OAuth client in Okta with narrow custom scopes, its secret held in HashiCorp Vault rather than in code. Done when the agent fetches the secret at runtime, gets a short-lived token, and is denied when it attempts a write.
