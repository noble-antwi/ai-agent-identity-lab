# Governed support assistant

**Status:** Not started

## Goal
An AI support assistant on the public Biira Bank site, governed as a non-human identity end to end: its own scoped directory account, short-lived credentials from Vault, firewall rules limiting what it can reach, and every action shipped to the SIEM and attributable. The agent does real work; the point is how it is governed while doing it. Done when a visitor's question is answered from lab data and the whole path is visible in Wazuh, including a denied attempt when the agent steps out of scope.
